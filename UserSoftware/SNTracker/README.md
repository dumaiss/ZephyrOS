# SNTrackerKos

SNTrackerKos is the native KonaOS port of the assembly SNTracker in the
adjacent `SNTracker` project. It plays the same bounded ZTR v1 tracker files on
all four Afternoon Blend SN76489-compatible PSGs.

The port retains the original player's meaningful behavior rather than
flattening songs to a register stream:

- 16 fixed logical channels mapped across four PSGs
- sparse patterns and the 16-channel order list
- volume, pitch, arpeggio, noise/duty and phase-reset macros
- macro delay, step, loop and active/passive release behavior
- arpeggio, volume slide, legato, one-tick decrease, fast slide and stop effects
- persistent notation arpeggios and hairpins
- per-song 96-entry tuning/divisor table and fine-pitch macros
- strict whole-file bounds and structure validation
- CP/M 128-byte-record copies with verified `1Ah` tail padding
- one-pass order lookup and cached PSG registers for dense 16-channel songs

Like the assembly implementation, timer code only publishes due ticks. Pattern
decoding, macro/effect processing, UI updates and PSG writes happen in normal
foreground context. A byte-sized producer/consumer tick queue avoids a shared
read-modify-write counter between the KonaOS event callback and foreground.
The player takes `/dev/sound` exclusively and batches every changed PSG
register for a tracker tick into one `sound_write()` call. This replaces the
old diagnostic-port call per byte and lets the driver validate and emit the
whole four-chip update in order. Device reset and exclusive release silence
all PSGs on startup and every exit path.
ZTR files are loaded before playback in direct 4 KiB transfers, matching the
current KonaOS SD-card transfer optimum; no storage operation occurs while a
song is playing.

## Build

From this directory:

```sh
make
```

The Makefile extracts and links against
`ZephyrOS/build/kos-sdk-0.1.0.tar.gz`. Replacing that archive causes the local
SDK copy to be refreshed and the application to be relinked automatically.
The executable is `build/user/sntrack.exe`.

`make test` runs the C loader and structural validator against both supplied
ZTR songs, then validates the packed KonaOS executable.

## Run

Copy `sntrack.exe` and a `.ztr` song to a KonaOS filesystem, then run:

```text
sntrack night-market.ztr
```

Press `Q` or Escape to stop. After each empty input poll, `idle()` halts the
CPU until the next interrupt; timer events keep playback advancing without a
busy polling loop or its audible bus noise. The heartbeat remains limited to
at most once every four song seconds.

Example ZTR files can be generated by the sibling assembly project:

```sh
make -C ../SNTracker song csm-song
```

That produces `../SNTracker/songs/night-market.ztr` and
`../SNTracker/songs/RunawayCircuit.ztr`.

# Sound fixture provenance

Every fixture is generated by the checked-in script
`tests/snd/fixtures/gen_fixtures.py` (run from the repository root);
the files it writes are committed beside it.  Regeneration overwrites
them; run it only to record a deliberate source change.

## Good fixtures

| Fixture | Provenance |
| --- | --- |
| `night-market.ztr` | `../Zephyr-80/Code/HOST/SNTracker/songs/night-market.ztr`, copied byte for byte (20,234 bytes). |
| `RunawayCircuit.ztr` | `../Zephyr-80/Code/HOST/SNTracker/songs/RunawayCircuit.ztr`, copied byte for byte (17,550 bytes). |
| `run-shortwaits.zvg` | compiled by `../Zephyr-80/Code/HOST/VGMPlayer/tools/compile_vgm.py` (ZVGC v2, 60 Hz) from a VGM written by the generator: bursts of same-tick writes (the 80h-8Fh write runs) separated by short waits (40h-7Fh), 130 ticks. |
| `wait16.zvg` | the same compiler and generator: writes separated by 100-tick gaps (the 02h WAIT16 commands), 310 ticks. |

## Malformed fixtures

`malformed/` holds one fixture per validation rule, each a one-byte (or
one-cut) mutation of a good fixture, named after the rule:

- the ZTR rules come from `ztr.c`'s ordered validation, which is
  `ZTR-Format.md`'s header, section, string, instrument, macro, pattern
  and note-table checks plus the CP/M record-tail rule;
- the ZVGC fixtures cover every header check of `validate_header` and
  the decoder's opcode checks (an unknown opcode, a zero WAIT16, a
  command truncated at the stream's end).

The oracle's outcome for each (the stage and the result line) is pinned
in `tests/snd/golden/malformed.md`; `tests/snd/oracle/make_malformed.py`
prints that table from the oracles' current output.
